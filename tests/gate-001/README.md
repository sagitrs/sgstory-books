### A8-whitelist-probe.mjs —— 白名单守卫探针（`books#151` 起）

用法：`ENGINE=<引擎检出> node A8-whitelist-probe.mjs`（cwd = books 检出，产物须已构建）。

它清干净 `span1Events`，再只移动到一个层，读账键，用来断「**只有白名单内的层才开事件账**」：

```
moveTo L1（白名单外）⇒ 账键须为 []
moveTo L9（白名单外）⇒ 账键须为 []
moveTo L5（白名单内）⇒ 账键须为 ["L5"]
```

★来历：`books#151` 的 D 席阻断（`onEnter` 裸调 `ensureDraw`）由我以本探针**同装具前后对跑**证实 ——
  改动前 L1／L9 皆被抽（并因此**耗掉随机单元**，破坏「同随机源 ⇒ 同结果」），改动后皆不开账。
★当前以**人读**为主（未接 `run-all.sh`）：它判的是「白名单守卫」这一条设计契约，属特定笔次的判据。
