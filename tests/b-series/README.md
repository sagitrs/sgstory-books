★**读法（★与 `tests/gate-001` 不同，务必先看）**：
- **判据红** ⇒ **本族当前的预期状态** ｜**红旗**（坏档／崩／零出声／早退）⇒ **✗ 预期**，须先消。
- 装置/环境错（引擎根不对、产物缺、jsdom 不可得）⇒ `rc=2`，**✗ 得计为判据红**。
- ★`rc≠0` 而**零条 `✗`** ⇒ **红旗**（装置坏）—— ★「崩溃不算红」是硬条。
