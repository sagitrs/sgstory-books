# 舞台装置 · 裁决与考古

本文件收录与"舞台装置"（台词、记录、线索物、伏笔）相关的整理结论，供重写时查考。故事本体见 [outline.md](outline.md)，目录与来源说明见 [README.md](README.md)。旧版原文的查找锚点（删除提交与恢复提交）见 README「大纲是怎么来的」。

> **总注（与 README 双重注明）**：本文件所录的一切舞台装置——换哨、引路哨、老妇谜语、"它有名字，有家"、世界三律等——**仅作为历史版本事实的记录**，供考古与查证。除"单哨"这一裁决约束本目录自身的行文（outline 与 settings 均按单哨撰写）之外，**所录装置不构成对后续写作者的任何约束或建议**：采纳、改造或弃用任一装置，皆由作者自行定夺。本目录为后续作者保留充分自由度。

## 哨的支数：旧版两套口径冲突，本目录裁决为单哨

旧版内部存在两套互相冲突的口径，不是单侧的笔误：

**单哨一侧**：

- 换哨一幕：「把你那支锈的接了过去，收进袖子——像收一件本就在她那儿的东西」（`50-ch3.twee:391`）；
- 正设门 v16 补正 #7：换哨改为与**当时的**女巫交换（`gates/canon.mjs:96`）；
- 世界三律曾以「一支哨子」支持此侧（`70-codex.twee:25`）——但三律本身已过时（见「旧版事实记录」），仅作历史锚点，不构成裁决依据。

**双哨一侧**：

- 图鉴条目名即作「**坏哨**（锈在门边那支）」，暗示另有一支「好哨」（`70-codex.twee:88`）；
- 「§5.5 **两支哨子的分工**：坏哨（引路）在公开场合；好哨（认人）在长桌尽头那位手里」（`15-tables.twee:3078-3085`）；
- 「坏哨」「好哨」两条物品定义（`15-tables.twee:828/832`，来历注「守林人家削的引路哨」），且正设门 `KEY_CHAIN` 同时登记双哨（`gates/canon.mjs:255`）。

**裁决**：取**单哨**——依据为正设权威口径与换哨一幕收袖句的闭合。**旧版 §5.5 与 `KEY_CHAIN` 的双哨登记，自本目录起废止**；重写者请勿照旧版物品表或正设门复刻两支哨。

**引路哨装置**：守林人家削引路哨（连同旧版一切"第二支哨"的形态）为已过时设定，仅作考古记录；本次整理不采纳（理由留档：哨太多易引起读者混乱）。后续作者是否采用类似的第二支哨装置，悉听尊便，不受此记录约束。

**换哨装置与时环**：换哨是一种舞台装置，且单哨之下它必然造成设定 bug——换哨一幕上同一支哨两份并存（未锈的交予旅人，锈的她收去），环上没有起点。本次整理留档的收束方案：终局吹响之后，让哨化为光点消散——未锈的那支出场即逝，世上自始至终只有一支（门边那支锈哨），时环就此闭合。此方案与换哨装置本身是否采用，均由后续作者自定。

## 老妇人的谜语：过时设定，仅作考古

旧版里宴厅角落的老妇会说出一句谜语式的话（"缺的不是咒，是等一个不在场的人把话说完"），且只有集齐跨时代证据的玩家才能听到。按正设，这位老妇是晚年的女巫穿越回来的——她不该透露任何信息，何况她知道的事日记里都已经写了；所以她"说什么"本身都是设定 bug。

处置（本次整理口径的留档）：谜语不采纳，仅作考古记录；老妇人按原始设定**隐藏身份**——场景中她只是宴席上一位不知名的老妇人，不发一言、无人识得，其真实身份（晚年的女巫）只作设定集里的后日谈彩蛋，不进任何场景文本（与 rewrite-notes「呈现纪律·双读纪律」同一条约束）。谜语装置是否在重写中复活、老妇如何处置，最终由后续作者自定，不受此记录约束。
