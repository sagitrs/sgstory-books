# 迷雾森林（mist-forest）· 重制大纲

## 这是什么

本目录存放《迷雾森林》的**故事大纲**，供从头重写这个故事时参考。

《迷雾森林》副题"送星归位"，讲的是一个外来旅人走进常年大雾的森林，想看看塔底传说的龙还在不在，结果发现那不是龙，而是一颗迷路的星——雾就是它睡着时漏出来的力气。故事的主线不是屠龙，而是想办法把这颗星送回天上的家。

## 目录

- [outline.md](outline.md) —— 故事本体：故事梗概、三百年前的正史、三幕主线。
- [settings.md](settings.md) —— 设定集：世界观、守塔的人家与三器、星器与星术、关键真相；旧版原有与后续补充的设定统一收录于此。
- [devices.md](devices.md) —— 舞台装置的裁决与考古：哨支数裁决（旧版两套口径冲突）、引路哨与老妇谜语降为过时设定（仅作考古）、换哨时环的收束方案留档、旧版事实记录（含已过时的世界三律）、台词与记录类装置。

> **注明**：devices.md 所录的一切舞台装置，**仅作为历史版本事实的记录**——除"单哨"裁决约束本目录自身行文外，不构成对后续写作者的任何约束或建议；采纳、改造或弃用任一装置，皆由作者自行定夺。本目录为后续作者保留充分自由度（devices.md 文首总注与此双重注明）。
- [rewrite-notes.md](rewrite-notes.md) —— 新旧版差异与重写建议：整理原则、与旧版的具体差异、旧版结局整理（仅供参详）、对重写者的建议。

## 大纲是怎么来的

旧版《迷雾森林》是 sgstory 引擎仓在 0.0.1-alpha 探索期写的一个内置故事，放在 `stories/mist-forest/` 目录下。探索期收官时，这批故事在提交 `sagitrs/sgstory@16b8f355`（feat(#1004) B2a：删 `mist-forest` 与 `hollow-cave`）里被整体删除；删除前最后的完整版本保存在它的父提交 `6783e093` 里。本目录的内容，就是从那里恢复、整理出来的。

旧版正文共有五份文件：三章（30/40/50）、结局（60）、设定集（70），另有一份数据表（15-tables）记录着道具与线索的图鉴信息；同目录还伴有一整套门测试与矩阵数据（`gates/*.mjs` 24 个、`gates/equiv-baseline/` 6 份、`matrix.json` 等），本大纲不继承。整理时参考了正文与数据表；整理的取舍与差异见 [rewrite-notes.md](rewrite-notes.md)。
