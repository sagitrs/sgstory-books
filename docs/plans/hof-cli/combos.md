# 装备／状态组合与规则表（`books#576`）

References [sgstory-books#576](https://github.com/sagitrs/sgstory-books/issues/576)。本页是**游戏层**的规则表；数值不在本页写死，一律可由 [`content.mjs`](../../../stories/hof-cli/content.mjs) 的 `COMBO_RULES`／`COMBOS` 与 [`game.mjs`](../../../stories/hof-cli/game.mjs) 的 `组合效果()` 复算（**单一实现**，与 `counterChance()` 同源常量：`WEAPON_STEP`＝15、`COUNTER_BLESSING`＝15、`COUNTER_CURSE`＝15）。

## 规则表

| 维度 | 规则 | 复算方式 |
|---|---|---|
| **顺序** | 基础反扑概率 → 武器（`tier × 15`）→ 祝福（−15）→ 诅咒（+15）→ 夹取 `[5, 95]`；**减伤只在伤害结算时按护甲取一次** | `counterChance(base, tier, blessed, cursed)` 与 `组合效果(s).净额` 同源；`battle()` 的 `max(0, roll − armor)` |
| **叠加** | **同类各计一次**：武器只取在装那件，祝福与诅咒各一次；同一优势**不**同时改「概率」与「次数」 | `组合效果(s)` 返回 `武器减／祝福减／诅咒增／净额` |
| **互斥** | 祝福与诅咒**可并存**，但只按**净额**计入概率（−15 + 15 ＝ 0），不各自另算一份 | `净额 = −武器减 − 祝福减 + 诅咒增` |
| **消耗** | 塔门协助承诺（`binding`）**只助一次**；用后 `consumed` 置真，不得二次协助 | `assisted(r)` ＋ `组合效果(s).生效` 是否含 `bulwark` |
| **清除** | 换装**只清本槽**（另一槽与祝福／诅咒保留）；**死亡**清空全部装备与祝福／诅咒；**存读**原样保留（含 `consumed`） | `apply('equip-<id>')`；`restore` 后的 `组合效果` 与存前逐项相同 |

## 三组组合（用途不同）

| id | 名称 | 用途 | 生效判据 | 可复算的作用 |
|---|---|---|---|---|
| `assault` | 破甲突击 | **进攻**：把反击概率压到接近下限 | 在装 `sabre`（tier 3）＋ 祝福 | 净额 −60 ⇒ `base − 60`，夹取到 5 |
| `bulwark` | 铁壁守夜 | **防守**：把每次有效反击伤害压到最低，并用掉塔门承诺 | 在装 `mail`（armor 3）＋ `assisted()` 为真 | 每次有效伤害 `max(0, roll − 3)`；承诺用后 `consumed` 置真 |
| `reckless` | 诅咒贪财 | **风险**：以负状态换更高反击概率（与祝福并存时按净额） | `curse` 为真 | 净额 +15；与祝福并存时净额不变（互斥面只算一次） |

组合之间**可以同存**（例如 `assault` ＋ `reckless`）；`组合效果(s).生效` 列出全部生效项，且**概率只按净额算一次**。

## 玩家可见面

`view(s).bag` 在**有组合生效时**追加一行 `组合：<名称>（<用途>）`；无组合时不出现该行（对既有状态零影响）。换装后该组合若不再成立，这一行随即消失 —— 这就是「正常 CLI 改装备后结果可解释」的落点。
