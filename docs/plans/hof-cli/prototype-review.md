## 先读哪几件

1. [规格](../../../stories/hof-cli/spec.md)先定试作参数、保存/跨局语义与不包含项。
2. [内容](../../../stories/hof-cli/content.mjs)是原创节点图、敌人、装备与解锁；[行为](../../../stories/hof-cli/game.mjs)分状态验证、概率/整场战斗、合法选项、事件结算与纯视图。
3. [独立pin](../../../stories/hof-cli/engine-ref.json)锚合法合入的完整引擎；[产品入口](../../../stories/hof-cli/play.mjs)经既有同一pin门核定后才导入真实接口1，不复制引擎代码或读网页pin。
4. [登记](../../../tests/hof-cli/registry.json)列42个unit/8个正常CLI用例及两把刀，源在unit/rules.test.mjs和e2e/player.test.mjs。前者允许构造规则边界；后者只从正常终端操作，测试本身不import运行时、不造状态/改档/换旅程内RNG。
5. [装置说明](../../../tools/cli/README.md)给计数、实际嵌套工具对账、退出码、私有临时目录、进程组预算与两树只读。正式CI接线按 [契约](test-contract.md) 和Tester公开许可核，不以本地字符串门替代Actions加载事实。

| #570验收面 | 实际实现 | 具名判据 |
|---|---|---|
| 原创可完成一局，不仅菜单 | 无回边节点图、事件、shop、三普通敌组和elite/beacon终点 | E01整局胜、E03自然败、E06粮尽合法退 |
| 两次真实路线选择 | fork的沼泽/崖道，forktwo的林地/沙地；事件、粮食、敌组都不同 | U13/U16/U17/U18/U28，E01/E05/E06 |
| 资源与足额前置 | 事件与移动合计成本；不够不扣费、不抽随机 | U14/U15/U17/U20/U28，E06/E07 |
| 商店/装备/消耗品 | 六件物品、自动装备/换装、非叠加、药上限/满血拒绝 | U19–U27，E01真实买/装备/用药 |
| 整场战斗而非逐回合 | potential=count×endurance，先反击判定再有效伤害骰，死亡停余攻 | U02–U11、U22、U30、E01/E03/E05 |
| 自然无伤/护甲真实生效 | 未反击不抽伤害，有效伤害可被甲减0 | U05/U07/U08/U09；H1护甲真实副本刀 |
| 胜败一次性结算 | finish与profile同事务；死亡清道具/粮、金币折半，无胜利奖励 | U31–U33、E01/E03/E06 |
| 实际下一局解锁 | 胜解锁可用潮渠；死解锁可带护胸/真实商店折价 | U26/U34–U36、E02/E03；H2下一局潮渠实际选项刀 |
| 手动真实存读/跨进程 | profile+run同引擎信封，恢复才替换，不自动账户存档 | U40/U42、E02/E04/E08 |
| 随机流、动作日志与原子性 | 只调用真实引擎Session；handler末段失败也不提交半场 | U16/U40/U41；E04真实战斗跨进程一致、E07查询不消费 |
| 可判计数/非空/失效自证 | TAP、实际文件、登记名字、状态码全核；两族各4项自证另计 | test.mjs、registry.json；缺文件/空登记/非Git/卡CLI的临时装置反控 |
| 正式版本接入/不漂浮 | 独立完整ref，阶段一导出、阶段二核检出；不从JSON另造ref解析器 | 既有check-engine-pin、产品bootstrap、现头平台实际job |
| 工具/CI不静默漏面 | tools/cli实际文件与两张表、真实workflow调用对应；player核实际import | check-ci门及配对内存反控，旧平面门单独跑 |
| 网页隔离 | 相对受检PR基座，网页pin/三档旧workflow逐字相同；不永久冻住未来合法网页更新 | 新静态门当前基座对账；旧门及平台babel-tests另计 |

U/E编号是登记中具名测试的前缀，不是没有断言的覆盖口号。42/8是产品用例，不与命令数、刀、静态反控、旧网页/引擎断言相加。每族报告通过/产品失败/环境作废/未覆盖，问题=后三者之和，计划=通过+问题；读不到登记时计划未知，不能造0/0绿。

## 边界及交付层次

原创行为模块只消费合入CLI，不移植引擎补缺、旧网页规则或商业游戏内容。低级碰撞/剧情文本不是实时沙箱，读档也不是可信在线账户。手动保存后才能跨进程保留长期记录；旧档回读会回退后来进度。本次不会把测试夹具冒作游戏交付。

分层提交为规格/真实pin、主行为与启动、规则/真实玩家测试与装置、说明/CI及契约。尚未合入的任何头都不是需求已验收；许可仅本实施PR合入前有效，换头须重取证据/CI/非作者票。

未覆盖：Windows/macOS、真DOM/视觉、完整商业平衡/大规模内容、模型试玩/费用测量、自动账户/防篡改、多进程存档冲突、断电耐久、迁移旧档、实时/逐回合战斗。网页nightly的已知红另见 [#584](https://github.com/sagitrs/sgstory-books/issues/584)，既不写成CLI红，也不抹成全仓绿。
