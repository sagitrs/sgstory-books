# 玩法侧设计笔记

> 本文件收录从 [layers.md](layers.md) 移出的玩法与工程向设计观察，使 layers 保持「道具与怪物设计参考」的射程（体例与 `docs/plans/forest/` 的设定／建议分文件一致）。所录皆为参考，不构成对玩法或后续作者的约束或建议。

- **断代梯度即难度梯度**：敌人与道具沿七阶断代推进，战斗数值与机制复杂度随层自然爬升。
- **单向门即分段锁**：每个十层段是封闭的养成区间，跨段不可回头——天然的章节与存档结构。
- **段内资源即成长线**：段间散置的建设物资对应"收集资源成长"的循环；大空洞是整备与社交区，段间层是战斗区。
- **随机换卡的落点**：文明段固定、段内随机——层内敌人组合、精英与掉落皆可随机化。
- **同一谱系的断代对照**：一件兵器的谱系（如"矛"：木矛→青铜矛→骑枪→刺刀步枪→振动刃）可贯穿五十层，作为收集与成长的可视化。
