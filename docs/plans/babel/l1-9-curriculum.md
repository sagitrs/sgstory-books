九层共用地图/事件/出口框架，是一个教学世界的九区域，不另占普通远征的第21世界；固定的是教学编排，不是骰果或必胜。以下是目标/提示的权威文字，不是本评已完成代码或亲测。

| 层 | 学习目标 | 交付边界 |
|---|---|---|
| L1 | **首战与武器**：认识战斗动作、真实空手入口、武器拾取与装备 | 不用强制成功代替“空手可胜”的正常随机验收，不把捡武器做成第二发货路径。 |
| L2 | **护甲与背包**：理解装备对战斗的作用、战后绷带与背包状态 | 物品按真实ID/容量/状态进入背包；不能因文案写了“获得”就算实际到手。 |
| L3 | **治疗与战前检查**：使用道具、理解治疗门与迎战准备 | 沿真实道具/门控；不强制玩家死一次示范，不把命中后高伤等同必定命中。 |
| L4 | **钥匙、宝箱与换装**：物品用途、开箱与中甲差异、下一阶段整备 | 保持既定固定引导弧，不以“必须回城”代替准备，不增提前传送资格。 |
| L5 | **事件取舍**：基础战后读懂抽二择一与明确放弃 | 放弃不补取另一支，去掉玩家预知选卡依赖。 |
| L6 | **工具与资源**：读懂所需工具、实例耐久、节点余量与实际产出 | 课程提示不能只有抽中采集才可理解；缺工具说明原因，不吃掉尚可补足的机会。 |
| L7 | **额外风险**：识别第二战、收益和资源消耗，主动选择或放弃 | 不把池中出现当必须选择，不用指定骰面证明收益/胜率平衡。 |
| L8 | **恢复与Boss准备**：使用固定温泉、识别恢复范围和保留资源 | 温泉不入随机池；不恢复工具耐久/耗材、不清通用长期正面效果。故事预知退役由B5迁移，不借温泉扩大清除表。 |
| L9 | **头目门槛**：准备区→固定不眠者→胜利后前进至L10 | 前进门不等于返城门；胜利事实必须真实结算，不新增随机池或额外普通战作教学门。 |
