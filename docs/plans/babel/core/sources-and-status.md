## 2. v1.3 核心裁定的继承与修订

作者提供的 v1.3 模块稿包含十二份 Markdown，本仓本次不保存全稿。下列是其中《世界设定与作者裁定》（输入文件名 `02-world.md`）“作者已确定的世界规则与叙事边界”的逐字摘录；这些文件名指输入稿，不是假称本仓已有对应文件。

**旧来源条目：只继承复生者的死亡／灵魂复生流程；“人人外部死亡、不用自然后代”已由下一节作者回复替代，不作现行人口限制。**

> 塔内的人都曾在外部世界死亡，灵魂被捕捉后在塔中复生。 他们与主角具有相同的来源，不用原生居民、自然繁衍的后代或虚拟 NPC 解释人口。长期留居、不断进入的候选人及其生产活动维持城市。

**永久死亡：**

> 塔中死亡永久终止这次机会。 死者被判为没有适应能力，不会再被给予复活机会。世界存在复生技术，永久失败来自筛选制度；不是宇宙中根本没有复生能力。读档与重开属于玩家操作，不能成为角色可使用的复活能力。

**主要筛选与永生条件，分别摘引原条目中的两句：**

> 真正的主要筛选在 L40–L49。

> 人工天堂要求 100% 义肢化，才能实现永生。

**官方谎言与目的：**

> 官方说辞与真实目的分开。 “这里是 100 年后的世界”“游戏帮助复生者寻找自己想停留的时代”为谎言；真正目标是选择适应天堂机体、愿意参与其建设的灵魂。“突破试炼取得永生资格”作为激励，其资格条件须与最终揭示一致。

**四城比较：**

> 四城构成亲历的比较。 玩家在 L10、L20、L30、L40 生活、建设、出征并形成归属。L10 与 L40 制度黑暗，L20 与 L30 有真实改善；玩家自主判断是否继续上行，以及天堂相比赛博朋克是进步、退步或混合。

**隐藏历史：**

> 作者已确定的隐藏历史：地表人类灭绝后，旧人类为了重建文明史而掩盖旧文明、重塑星球表面，投放最适合自然生存的智人克隆体，并诱导新人类的演化／历史进程与旧人类基本一致。此处是作者层面的真相，不代表玩家只看见一件科技道具便能知道全部经过。

**证据的已定边界，不作为额外核心条目：**

> 证据不可越级。 魔法道具重鉴定能揭示塔内中世纪魔法史由人为构造，不能直接证明真实历史上存在古代超科技文明，也不能单凭它推翻“100 年后”的官方说法。古文明、地表灭绝与历史重塑须由另一条历史证据链逐步支持。

上述摘录仅移除原条目首句的 Markdown 粗体标记，文字、空格与标点保留。首句后原来紧接的空格也保留。继承的“旧人类在轨道人造天堂存续”还与[既有世界观需求 #69](https://github.com/sagitrs/sgstory-books/issues/69)所述轨道太空站前提相衔接；不由此继承其人口衰减解释、濒死来源或失忆结局。

## 3. 后续作者第一轮回复

以下是本席会话记录中的逐字原文，不是摘要：

> 1，主角来自当代，现在2026年，生前地表文明正常存在；2，能快速返回城镇的原因是来的路上敌对单位都死了，与科技无关，只是为了方便玩家；3，复生肉身与原生肉身完全相同，可以生育，限制地下人口的主要来自资源限制。资源主要来自探索地下城（为了解释资源量无限，可以认为10n+1~10n+9层位于随机异空间，10n进入10n+1层也是通过传送门，只不过是双向的）。我不确定这个设定是否过于复杂，你可以评估；4，非致命失败可以选择逃跑，前提是在战斗中逃跑判定成功。逃离会直接回到城镇，但会随机失去携带的一半道具。

与核心直接相关的解释：

- 真实地表 2026、生前正常文明、相同且可生育的复生肉身，是明确回复。
- 塔内可以自然出生后代，撤回 v1.3 中“塔内每个人都曾在外部死亡、不能有后代”的旧限制。后代没有虚构的地表生前身份。
- 普通快速回城是沿清路返程的操作摘要；付费传送道具若保留，其用途不能冒充普通返程的必需条件。
- 战斗逃跑成功才直接回城并随机失去随身一半道具，不等于死亡以后获救。计数、舍入、穿戴物／货币／关键物范围等算法未定。
- 随机异空间与双向入口是要求评估的方案，不自动定为全部地图的硬规则；这也不裁定所有跨章门双向。
- 地表禁返、死亡到复生的精确间隔、最终生育后果未在这段回复中决定。
