# 普通远征价值参考：目录价与原创局部拟合

本附录服务[核心04](04-expedition-economy-and-progression.md#72-不用一个价格字段包办)。从v0.1工作稿只迁入价格锚点与拟合，不继承其20/25kg硬限、1金币物资、检定疲劳、b/k试算或返城自动清疲劳。作者估价方向见[原文第3节](expedition-author-decisions-2026-10-06.md#3-装备估价制造重量与贡献)。以下不是本作已平衡的商店、通量或收购参数。

## 1. 已有装备的目录锚点

来源使用D&D 3.5 SRD，不混5e。价格单位为金币；魔法加价在精制基底上计算。资料币制为1gp=10sp=100cp，不说明本作旧硬币与新金币的换算已裁定。

| 项目 | 手册参考价/加价 | 关键说明 |
|---|---:|---|
| 匕首 / 短剑 / 长剑 / 巨剑 | 2 / 10 / 15 / 50 | 伤害骰、手数、熟练与重击不同，不能只按平均伤害反推 |
| 皮甲 / 镶钉皮甲 / 链甲衫 | 10 / 25 / 100 | 护甲AC分别+2/+3/+4 |
| 链甲 / 胸甲 / 半身甲 / 全身甲 | 150 / 200 / 600 / 1500 | 护甲AC分别+5/+5/+7/+8；敏捷上限和罚值有差异 |
| 重木盾 / 重钢盾 | 7 / 20 | 均盾牌AC+2；不是另一套护甲AC |
| 精制单头武器 | 普通价+300 | 命中+1，不加伤害；不与魔法增强叠加 |
| 精制甲/盾 | 普通价+150 | 护甲检定罚值减轻1，不自动加AC |
| 魔法武器增强n | 精制价+2000n² | 通常同时提升命中与伤害，不能把两者再分别计价 |
| 魔法甲/盾增强n | 精制价+1000n² | 是既有护甲/盾牌的增强，不是任意AC来源 |

例：精制长剑315金币，+1长剑2315金币；精制链甲衫250金币，+1链甲衫1250金币。L10不能制造精制或魔法装备，不等于禁止进口，也不改变手册锚点；本作简化铁环甲不能直接当SRD链甲价格或完整熟练模型。

普通手册装备优先使用具体目录价；一般出售半价、贸易品全价是资料参考，不是本作自动批准的回收规则。参考价值V、买价P、回收资格/价格R、重量w分开，不可售不等于价值零。

## 2. 原创单效果的局部线性拟合

作者允许原创装备先作简单线性拟合，下表是助手提出的具体候选，不是SRD价格定律。对列明价格点作普通最小二乘拟合，`V_effect = an + c`；n为效果加值，不是人物等级。n=0计0；正加值仅在列明范围应用，不能给普通装备套负截距。计算保留精度，整件最后一次四舍五入到铜币；是否采用此结算精度仍是实现细则。

| 效果族 | 手册锚点 | 拟合范围 | 候选V_effect |
|---|---|---|---|
| 武器增强：命中与伤害一起提高 | 2000n² | n=1,2,3 | 8000n−20000/3 |
| 甲/盾增强AC | 1000n² | n=1,2,3 | 4000n−10000/3 |
| 偏斜AC / 自然护甲增强 | 各为2000n² | n=1,2,3 | 8000n−20000/3 |
| 单项能力值增强 | 1000n² | n=2,4,6 | 8000n−40000/3 |
| 全豁免抗力加值 | 1000n² | n=1,2,3 | 4000n−10000/3 |
| 单项技能表现加值（competence） | 100n² | n=1,2,3 | 400n−1000/3 |

例如原创能力+2/+4/+6拟合约2666.67/18666.67/34666.67金币，锚点为4000/16000/36000；武器增强+1/+2/+3拟合约1333.33/9333.33/17333.33，锚点为2000/8000/18000。残差是简化成本，不是手册新价格；已有+1长剑仍用2315，不被拟合覆盖。

整件原创装备候选为“选定的普通/精制基底价＋各独立效果估值”，不是SRD多能力造物规则的复刻。武器增强是一组效果；能力值引发的命中、AC、HP等派生收益不重复计钱。同效果/同源不叠加照正式规则。

纯命中加值不能不看类型就套武器增强。纯伤害、HP、主动能力、抗性/免疫、触及、控场、条件性加值和诅咒先类比具体物品或另登记价格。铜冠Listen环境加值不自动等于通用技能表现加值，七名河100旧硬币原创参考价不由本表重估。不按稀有度、材料名或“史诗”直接乘价。

范围外及没有锚点的效果不外推，也不默认零价通量。负面状态、不稳定或不可售资格不自动降低通量估价。新补给30金币、矿石标准份、b/k、通量生命周期与上限仍按核心04列为暂定/待定；本表算术正确不能证明一两次探索买得起物资。
