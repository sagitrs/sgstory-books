# 核心设定：删掉就会改变本作承诺的部分

本目录收录 **v1.4 核心候选**，只保留世界真相、主要风险和去留选择。只读这里，应能说明“主角是谁、塔为何存在、继续有什么代价、留下为什么成立”。具体制度、地图原理和剧情场景不在这里展开。

前三篇最初按[需求 #236](https://github.com/sagitrs/sgstory-books/issues/236)整理入库。本轮依[文档交付授权](https://github.com/sagitrs/sgstory-books/issues/411#issuecomment-6028630020)追加核心04，细化C7，不增加第八条世界观承诺。正文保留已定、作者暂定、建议、待定的区别；提PR或合入文档不等于所有参数获批、整体冻结或游戏已实现。

中心问题是：

> 我已经有可以生活的地方，为什么还要冒永久死亡的风险，去寻找一个未必更好的归宿？

## 核心不等于已经批准

目录回答“重要到什么程度”，状态回答“是谁决定的”：

- **已定**：作者明确裁定或未被替代的旧裁定。
- **作者提案／作者暂定**：作者提出要评估的方案或试行数值，不等于逐项冻结或已经验证。
- **建议**：判断应作为核心承诺的工作默认，仍待确认。
- **待定**：会影响核心选择、但尚未作决定的边界。

可选表现也可能有已定规范或参数。例如证据不越级、一半道具损失均已确定；前者是表现真相的设计规范，后者是退路的具体代价。本次保留与核心直接相关的边界，不把形式全部当成独立核心，也不因未迁入可选模块就撤销已定值。

## 依赖方向

可选表现应服从这里的承诺；核心不依赖一定选中某个遗迹场景、保险公司、传送门原理或 90 日期限。若不选一项表现，就删掉相应枝节；若它承担了必需功能，则用更简单的方式补足功能。具体已选参数的修改仍需作者确认。
