# 核心设定：删掉就会改变本作承诺的部分

本目录收录 **v1.4 核心候选**，只保留世界真相、主要风险和去留选择。只读这里，应能说明“主角是谁、塔为何存在、继续有什么代价、留下为什么成立”。具体制度、地图原理和剧情场景不在这里展开。

本次按作者要求先整理核心并提 PR，见[需求 #236](https://github.com/sagitrs/sgstory-books/issues/236)。正文保留已定、建议、待定的区别；提 PR 或合入文档都不等于所有建议获批、整体冻结或游戏已实现。

中心问题是：

> 我已经有可以生活的地方，为什么还要冒永久死亡的风险，去寻找一个未必更好的归宿？

## 核心不等于已经批准

目录回答“重要到什么程度”，状态回答“是谁决定的”：

- **已定**：作者明确裁定或未被替代的旧裁定。
- **作者提案**：作者提出要评估的方案，不等于已确认采用。
- **建议**：判断应作为核心承诺的工作默认，仍待确认。
- **待定**：会影响核心选择、但尚未作决定的边界。

可选表现也可能有已定规范或参数。例如证据不越级、一半道具损失均已确定；前者是表现真相的设计规范，后者是退路的具体代价。本次保留与核心直接相关的边界，不把形式全部当成独立核心，也不因未迁入可选模块就撤销已定值。

## 依赖方向

可选表现应服从这里的承诺；核心不依赖一定选中某个遗迹场景、保险公司、传送门原理或 90 日期限。若不选一项表现，就删掉相应枝节；若它承担了必需功能，则用更简单的方式补足功能。具体已选参数的修改仍需作者确认。

本次没有将可选模块、四城建筑／NPC细案、图片、规则服务审计或工程实施清单迁入本仓，因此不预建这些目录或留下悬空链接。作者原文、继承依据与未决问题见[核心来源与状态](sources-and-status.md)。

旧大纲、资源表和玩法笔记保留历史正文，由[上级阅读入口](../README.md)说明其定位；[系统维度附录](../dimensions.md)仍提供规则分段与装备等策划参考，不是完整实现证明。本 PR 没有修改故事或引擎。
