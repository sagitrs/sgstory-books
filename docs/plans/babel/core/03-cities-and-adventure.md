# 核心 03 · 四城对照与远征骨架

> v1.4 核心候选；重要度与批准状态分开。作者原文与继承依据见[核心来源与状态](sources-and-status.md)。

## C6 · 有改善，也有值得留下的地方

**【已定】**L10、L40 的制度黑暗，L20、L30 确有改善；四座城镇都能产生真实归属。不是每座好城最终都会露出同一张恶脸，也不是科技越先进越公正。

| 基地 | 必须保留的对照作用 |
|---|---|
| L10 | 生存压力与压迫，让第二次生命并不自动等于自由 |
| L20 | 互惠与合作，可以真实改善生活 |
| L30 | 稳定组织与公共保障，提供另一种真实好生活 |
| L40 | 技术先进但服务与权力不平等，身体便利与制度代价并存 |

作者在四城提案中提出的公会、军队、企业与人口梯度，是表现这些差异的一套方案，不把每个部门、比例和历史事件都升格成核心。

**核心理由：**如果所有城都不值得留下，攀登只剩逃离；如果全都一样，跨城也失去比较生活与制度的意义。

## C7 · 探索支持生活，返程支持归属

> **注（`sagitrs-developer` 2026-10-04，`books#239` 收口）**：本条在 v1.4 稿里的口径**已被 2026-10-03 决策①取代** ✓ —— **现实现＝付费卷轴**（`stories/babel/src/world/` 的现实做法：回城要花代价，而非 v1.4 设想的免费/自动供给）✓。★原文**逐字保留**（✗ 不维护第二套核心规则 ✓），本条注只指出现行实现与它的关系 ✓。

**【已定】**资源主要来自地下城探索，地下人口主要受资源限制。正常生育不会被隐蔽不育取消，也不要求只有主角为全城刷资源。

**【已定】**普通快速回城是省略沿已清理来路返回的操作，不靠科技瞬移，不应要求先购买回城卷轴。战斗逃跑是另一种有判定与代价的结果，不能混用。

**【建议，玩法工作默认】**保持战斗主导的剧情肉鸽，让玩家能在本章基地准备、探索、返程、恢复与建设关系，再决定留居或继续。章末成功不自动替玩家完成离开决定。

**【建议】**可持续探索不等于每日无成本无限供应。随机地图不撤销同一人物的死亡、主线领用、建设和记忆；重复玩法不能取消 C3 的生命风险和 C5 的真实成果。

**核心理由：**城镇只有进入下一层的按钮就无法成为生活；随机重置所有事实又会破坏归属与不可逆代价。
