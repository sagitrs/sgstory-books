采用 `世界.原型id`、`层位[].内容包`、`持久化.{世界级,场次级}` 的字段名与嵌套关系。本次冻结以下最低形与语义：

|---|---|

| `持久化.世界级` / `持久化.场次级` | 两者为事实键声明列表，元素为字符串，指向随后逐项登记的事实。此处是生命周期分类规格，**不是再复制两份运行状态，也不是新的存档真值**；实际清单依 D1-④ 后续补齐。 |

## 2 可复算【已定 · **效力待补证**】（裁文 §3 · ★**五点完整定义，✗ 简称**）

草案“同树＋同随机源＋同序”的方向可以采用，但须按以下完整定义写入正式规格，不能只保留简称：

1. **同版本**：故事/内容树与引擎 pin 均固定；注册及候选池的确定顺序也属于输入。同一原型名称不等于同一内容版本。
2. **同前置状态**：同一世界/场次的初始状态、选择历史、已提交进度与奖励账、可影响抽取的装备/效果和配置一致。只有同动作、但前置状态不同，不在等价承诺内。
3. **同实际随机输入**：明确随机算法/映射版本，并给出同一初始随机状态及后续状态推进，或同一显式注入单元值序列。**同名源、同构造函数、同用 `Math.random()` 均不足以证明这一点。** 注入序列耗尽必须显式失败，不回退真随机。
4. **同序**：玩家有效动作及其参数一致；随机消费用途、归属与先后一致；影响业务的外部输入须显式固定。单纯预览、重绘、查看与取消不能偷偷重抽或追加业务消费。异步完成顺序若影响结果，也须进入确定输入或由实现消除该依赖。
5. **同结果**：比较生成/抽取的内容引用及顺序、业务判定结果、提交后的真实状态、收益/进度与防重事实，以及本范围的随机消费记录；不要求时间戳、窗口排版或诊断文本逐字相同。

固定 pin 的 [05-dice.js](https://github.com/sagitrs/sgstory/blob/fb20f2a2d70bd14831e90546165f531d0ca8870c/src/core/05-dice.js#L15-L83)明确：共享的是纯算法，不是可变随机状态；默认源动态读取 `Math.random()`，实例可显式注入，序列耗尽抛错。因此本条批准的是**规格契约，不是宣称现有游戏已实现种子存读、完整回放或随机抽样验收**。随机接口、存档落点与判据实现仍按各自交付链另核；不冻结经济参数或概率平衡。
