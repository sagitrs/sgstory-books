# 核心 02 · 生命风险、机械身体与去留

> v1.4 核心候选；重要度与批准状态分开。作者原文与继承依据见[核心来源与状态](sources-and-status.md)。

## C3 · 真正死亡与存活撤退分开

**【已定】**塔中真正死亡永久结束这次生命机会。组织有复生技术，却拒绝再给塔内死者一次机会；“死者不适应”是制度判词，不是作品证实的心理学事实。读档、重开是玩家功能，不是世界内复活。

**【已定】**非致命失败不必一律终局：战斗中逃跑判定成功，可以直接回城并随机失去携带的一半道具。比例是已定参数，不因本次未迁入玩法细案而撤销；计数、舍入、穿戴物／货币／关键物范围等执行细节仍待定。

存活者的治疗与维修不是复生。死亡以后不能逃跑，也不能在后期拿到高级技术便撤销本局已经付出的生命代价。

**核心理由：**去掉永久风险，继续攀登不再是重大取舍；去掉存活撤退，所有失败又被混成死亡。

## C4 · 本人的机械永生与主动同意

**【已定】**主要机体适应筛选位于 L40–L49；天堂永生要求完整 **100% 机械承载**。伤损、医疗与真实便利可以推动义体接受，不把便利全部反转成骗局。

**【建议，原工作默认】**安装、稳定使用、同意最终转换和正式入籍不能被当成同一件事。求生治疗不是同意全改造，外接装备不是主体替换，不用高替换率或乖顺度自动判定愿意入籍。

**【建议】**永生属于同一存续主体，摆脱自然寿命上限而依赖维护；不是杀死本人再留下副本，也不承诺任何灾难下都不可毁灭。正式迁移有受保护交接，不先完成不可逆转换再询问同意。

**核心理由：**这是最后的身体与生活选择，不只是装备升级或一个隐藏态度分数。

## C5 · 真实归属与知情去留

**【已定】**四城都可以形成真实生活归属，L20、L30 的改善确实存在。

**【建议，原工作默认】**不能靠毁城、逐客、删除关系或停医逼玩家继续。暂留可以再上行；正式留居用本城生活后日谈收束本局。活着留下不是死亡或失败，也不自动获得天堂永生。探索成果、关系与同伴意愿被尊重，不因进入下一阶段清零。

**【建议】**不可逆选择以前说明实际条件：留居前知道本城生活与生命风险，最终迁移前知道招募目的、身体变化、维护、生育影响与出口。天堂有真好处，但加入与拒绝都不是唯一正确答案；拒绝某项工作也不应使正式生命保障被随意撤销。

**【待定，影响核心选择】**能否返回生前地表、塔内出生者的攀登／入籍资格、迁移对生育与亲子关系的后果。不能用表现层的某张地图、人口表或医疗设定偷偷代替这些决定。

**核心理由：**没有可靠的留下和拒绝选项，所谓归属与同意就变成必须上行的包装。

## 留给表现层的内容

创伤分类、维修渠道、独立诊所、L49 的具体通关支持、L50 的体验及交接流程、后日谈和返回旧城的具体安排，留给后续表现方案。本 PR 不迁入这些模块。表现设计仍须按 C3／C4 的已定与建议边界分清普通伤、非致命倒下、结构缺失、机械损坏和真正死亡；医疗或付费也不代替最终转换同意。
