## 先读什么

本目录先收录《巴别之井》**v1.4 核心候选**：战斗主导的剧情肉鸽，以真实第二次生命、永久风险和知情去留组织战斗与城镇生活。本次按[需求 #236](https://github.com/sagitrs/sgstory-books/issues/236)只整理核心及必要来源，不迁入可选模块、四城细案或图片，不修改游戏／引擎。

“核心”表示重要度，不表示所有建议已获批准。作者明确裁定、继承裁定、作者提案、工作建议、待定问题与已实现状态必须区分；文档合入也不代表整体冻结或功能验收。

## 来源与原创边界

早期大纲出自 2026-09-30 策划口径，后经作者提供的 v1.3 模块稿、后续直接回复和本轮核心分类整理。具体依据及状态见[核心来源记录](core/sources-and-status.md)，不将助手建议冒充作者原话。

背景母题参考《弥留之国的爱丽丝》《赛博朋克 2077》《乐园追放》，分别涉及死亡边界、机械身体与轨道天堂。仅取母题与氛围，不整包导入人物、地名、事件、宇宙学或现实年份。作品设定为原创，作者可以继续修订；已有明确裁定的修改须说明替代关系并同步关联内容。
