# 巴别之井（暂名）· 世界观大纲

## 这是什么

本目录存放一个**纯战斗向游戏**的世界观大纲。游戏的核心循环是重复挑战、随机换卡、收集资源成长、享受战斗乐趣——故事不是玩法的载体，**大纲仅作为道具与怪物设计的参考**。

## 目录

- [outline.md](outline.md) —— 世界观大纲：灵魂的捕捉与筛选、五十层地下城与四段文明、单向门法则、五十层终局的二择、设定留白。
- [layers.md](layers.md) —— 层级详表：各层段的文明形态与资源投放，及敌人、道具的断代梯度（含断代映射与本表前提）。
- [design-notes.md](design-notes.md) —— 玩法侧设计笔记：从 layers 移出的五条设计观察（难度梯度、分段锁、成长线、换卡落点、谱系可视化）。

> **注明**：本目录所录设定仅作设计参考与事实记录，不构成对后续写作者的约束或建议；采纳、改造或弃用任一条目，皆由作者自行定夺。

## 设定出处与版权

设定为原创，出自 2026-09-30 的策划口径。背景母题参考《弥留之国的爱丽丝》《赛博朋克 2077》《乐园追放》（濒死边界、义体与机械飞升、轨道天堂），仅取母题与氛围，无任何人物、地名、情节等素材引用。
