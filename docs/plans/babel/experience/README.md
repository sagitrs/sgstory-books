# 低成本体验设计

需求：[books #473](https://github.com/sagitrs/sgstory-books/issues/473)。整理日期：2026-10-07。

目标是让玩家知道“在哪里、找谁做什么、刚才发生什么”，而不是先学习一批人物专名和界面术语。本目录是依附核心的表现层设计，不新增核心承诺或游戏事实。

## 阅读入口

| 文档 | 用途 |
|---|---|
| [呈现与小样设计](low-cost-presentation.md) | 地点图、唯一身份模板、阅读与反馈、返城小结、低图回退及小规模验证 |
| [裁定与来源](decisions-and-sources.md) | 操作者原话、认可方向、助手整理细则、官方竞品参照、待确认项和证据限制 |

**批准状态：**游戏内NPC模板化、身份化，以世界内唯一身份代替姓名，是操作者明确约束；其余地点图、阅读反馈、旅途小结与小规模试用已获方向认可。具体称谓、画像、尺寸、路线与实现方式没有逐项冻结。

**交付状态：**本次只提交设计文档，不接入图像或运行代码，不改变引擎pin、存档、玩法、版本和发布条件。文档入库或合入不表示小样已实现、体验效果已证实或可以发布。
