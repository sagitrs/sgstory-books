# L10 First City：最简玩法设计候选

本篇按[需求 #308](https://github.com/sagitrs/sgstory-books/issues/308)整理本次讨论，不是实现说明。作者指定的方向是：**制度复杂度只影响剧情，L10 是机制最简单的城市**。服务、贡献口径、门槛和具体奴役事件仍是建议，状态与作者原文见[来源记录](L10-sources-and-status.md)。First City 和下文建筑英文名均为工作名，不是正式命名裁定。

本方案依附[生命与去留核心](../../core/02-life-body-and-choice.md)及[四城与探索核心](../../core/03-cities-and-adventure.md)，不另造第二套核心。L10 及其上方 L11–19 沿用 D&D 3.5／DND3；不新增规则数学、货币或价格换算。

## 1. 作者指定的玩家循环

进入 L10，探索地下城，出售带回的资源；累计售出一定量后取得居民证，一次性使用完整城镇服务。随后通过整备、装备与补给改善远征能力，积累经济和装备，挑战 L19。

玩家不购买或经营奴隶，也不从奴役取得生产与成长收益。成为奴隶即结束本局；具体达到条件的方式未定。

**城市新增的主进度建议只保留两项：**累计有效资源售出进度，以及是否持居民证。玩家已有的金币、物品、伤势、剧情和楼层进度仍归各自系统，不复制成城市评分。

建筑已经存在，不需要玩家建设五座建筑。居民证改变服务资格，不改变建筑等级；领证以后也不继续解锁城镇等级。信用、产权、政府、帮派与债役可以出现在剧情里，不做贷款经营、利息账户、地产、劳务拍卖或全城财政／人口模拟。旧共同工具项目和三种信用准备路线都不是首版必需任务。

## 2. 五处入口与服务资格

**【助手建议，待逐项确认】**所有建筑从入城起都可看见、进入和交谈。证前可以了解服务、人物和制度，不将没有居民证的人物故事一并隐藏。

| 建筑工作名 | 证前入口 | 证后一次性开放的服务候选 |
|---|---|---|
| Newcomers' Registry | 说明城规与领证条件，显示累计进度 | 免费领证，查询既得服务资格 |
| Ration House | 收购有效资源、支付金币并记进度；若沿用付费回城，必要返程用品须有证前入口 | 稳定的补给购买目录 |
| Ember Workshop | 人物交谈，预览装备与费用 | 购买、修理与整备少量装备；不增加复杂锻造系统 |
| Lamplight Infirmary | 说明伤势、治疗边界和证前保底恢复路径 | 付费治疗及选定的创伤处置 |
| Common Hearth | 临时落脚、最低基础休整和生活对白 | 稳定食宿、个人寄存与更多生活对白 |

服务目录、价格、时间和效果尚未制定。“解锁服务”不等于无限库存、免费供养、住宿全恢复或解除真死。医疗只能处理仍存活者；普通伤、非致命倒下、结构缺失和真正死亡不能混为一个回血按钮，也不把标准 Heal 的稳定伤者等同于直接恢复 HP。

### 证前必须能再次出发

出售入口和最低恢复入口不能锁在证件后面。未持证者应能进入 L11，取得普通资源，合法回城并再出发；否则“先领证才能获取领证材料”会形成循环依赖。

证前休整可以较慢，并按选定规则消耗世界时间，但必须说明能恢复什么、何时能再出发。不能默认补满道具、装备耐久或不可自然恢复的伤损。若常见伤势或返程成本会阻断这个循环，内容表须给出明确保底办法；不把无法休整突然改为卖身，也不新增隐藏的日历锁。

### 回城方式的实施衔接

本稿保留可重复远征／返城的设计目标，**不宣称免费返程已经是现行规则**。现有核心 C7 的普通清路返程正文与付费卷轴注记并存；[#259 的操作者批复](https://github.com/sagitrs/sgstory-books/issues/259#issuecomment-5979133432)已确认塔单向只限制步行回边，付费卷轴作为例外保留。

落地前须明确最终方式，以及证前如何获得和承担返程成本。若沿用卷轴，购买不能先要求居民证，其成本也必须纳入远征收益与最低休整预算。本稿不恢复向下步行边，不撤销卷轴，不绕过现有首战与事件阶段规则。更早的清路返程说明、当前版本批复与本稿目标的关系见[来源记录](L10-sources-and-status.md)。

## 3. 售货进度与居民证

**【助手建议，待作者确认】**将收购目录中有效资源的累计实际成交金币额作为进度。一次交易既给玩家金币，也增加售货进度；不另造贡献币，不要求领证时再支付一次费用。

- 只选择少量常见、稳定可获得的资源。资源种类、产量和收购价待内容表，不依赖稀有宝箱。
- 进度看累计售出，不看当前钱包。买装备、治疗或购买返程用品不减少已记进度；到门槛后免费领证。
- 装备、药品等转卖不计进度。首版建议商店不出售同类可计进度的原料，避免买进卖出刷证，而不建立复杂来源追踪。
- 成交前公开此次价格和新增进度；售货失败或取消不扣物、不付钱、不加进度，成功只记一次。
- 领证永久记录为本局资格，不作为成功逃跑时会掉落的随身物件。领取与读档不重复发放金币或奖励；领证也不等于已经正式留居。

完成进度以后仍可正常交易，但不继续积累隐藏城镇等级。本稿也不增加“持证才允许挑战 L19”的新楼层门。

### 门槛先定体验，再定金数

**【节奏建议，未经试玩】**以通常 2–3 次保守短远征作为首次领证的目标，而非强制往返次数。设一次典型短远征中有效资源的成交总额为 `R`，门槛候选为 `T=2R`。携带资源较多的玩家可以更早完成，不强制刷指定次数。

`R`、门槛、产量、回城与恢复成本均未确定；公式不是价格表或平衡结论。内容表必须同时检查进度和钱包，不能让玩家贡献足够却一直无力进行最低整备。已结算的敌人、采集和事件不重复领奖；新的资源来源及远征区刷新边界另定，不从“需要两次远征”推导出无成本重置。

## 4. 领证后的经济与装备成长

**【助手建议】**首版保留一个小装备目录、一个补给目录、选定的活人治疗／修理和寄存入口。成长来自真实探索收入，以及把收入投入下一次整备；不是自动发钱、复利账户或奴役收益。

玩家应能做直观选择：这次先换装备、补消耗品，还是保留金币处理伤势和返程？更充分的准备有助于取得更深处资源，但仍有损失和永久死亡风险；本稿不承诺装备购买必然转化为净利润或通关。

重复远征不是重新复制旧奖励。售货、花钱、领取证件和寄存需沿用同一局的事实；是否采用新物品与服务接口，留给后续开发票。本文未指定存档字段或实现 API。

## 5. 制度复杂度由剧情承载

**【表现建议】**不要求玩家经营制度，只让他看见具体的人和处境：

- 登记与收购时，说明谁有正常交易资格、谁受他人控制；掌权者可以用供给压力解释制度，但这不是作品证明奴役必要、正当或效率最优。
- 在工棚看见受役者有专业技能却不能自主支配劳动；主角可以交谈或参与局部支线，不提供购买这个人的按钮或奴隶产出面板。
- 医棚与共灶表现资源有限、照护和互助仍真实存在。人物不能仅成为升级按钮；普通低战力者也不是没有价值的消耗品。

支线可以改变对白或具体人物处境，但不要求先改革全城才能领证、整备或挑战 L19。法令、契约和多年债役可以用短剧情解释，不逼主角刷多年账户。

## 6. 奴役终局与其他结局分开

**【作者指定方向】**成为奴隶即 GAME OVER。首版不提供奴隶经营，也不在役籍中继续赚取升级资源。

**【助手建议，触发条件未定】**只在剧情明确主角已经失去人身自由、进入被支配身份时触发；不为该事件另建完整借贷、利息或破产系统。可考虑一个明确标注后果的“接受以自由抵偿”选项：选择前展示“将结束本局”，再确认后进入终局。这只是事件例子，不表示只有主动选择才可能受役，更不把普通求医隐蔽变为卖身。

最终节点必须说明危险来自哪里、怎样预防、有哪些可避免路径，以及何时已经失去自由。若采用强制捕获等其他事件，也要单独设计预警和判定，不能偷偷把普通非致命失败改成奴役条件。

以下情况本身不应自动触发：金币为零、尚未领证、买装备后缺现金、普通可偿还资源欠账、非致命倒下或成功逃跑。玩家已经花掉的钱也不应倒扣居民证。具体终局状态仍需确认。

**【终局表达建议】**显示“失去自由，本次攀登结束”，保存独立失败原因；不把 HP 改为零，不授予死亡状态，也不调用复活。真死另按 C3 处理，读档／重开仍是玩家功能。这条游戏结束规则不意味着世界里的其他受役者已经死亡或永远不可能恢复自由。

## 7. L19 与去留

击败 L19 后应由玩家主动决定继续前往 L20，还是留在 L10；领证、暂住和正式留居是不同的事。**正常留居不是奴役、死亡或失败。**正式留居与后日谈的具体表现继续依核心 C5 的批准状态处理，本稿不靠毁城、取消医疗或杀死重要人物逼玩家上行。

本方案到这里收束；L20 后续增加什么合作或任务机制另行设计，不把早期三条信用路线和共同项目重新设成 L10 必做。

## 8. 下一步确认与验证

本 PR 只交付文本。实施前至少确认：有效资源目录与价格、证前恢复和回城办法、证后服务效果、门槛，以及具体奴役事件和终局判定；来源记录保留这些未决项。

获得开发授权后再验证：证前闭环可持续；成交只结算一次；消费不减进度；领证持久且不重奖；读档恢复同一资格和交易事实；普通返程、成功战逃及道具损失、非致命状态、真正死亡、奴役终局与正常留居分别处理。再用实际短远征检查领证节奏和整备收益，不能以文档检查代替这些运行结果。
