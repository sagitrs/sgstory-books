# L10 最简玩法：来源、状态与实施边界

本记录只说明[L10 候选正文](L10-first-city.md)的依据，不增加另一套设定。需求与提交授权见[#308](https://github.com/sagitrs/sgstory-books/issues/308)；该票逐字保存下面两段作者原话，便于在仓内外核对。

## 1. 作者原文与本次授权

### 玩法方向

> 可以，但我个人建议L10设定复杂度只影响剧情设计，游玩体验上我希望L10是机制上最简单的城市，例如玩家实质上因自身观念不会购买奴隶，一旦达到成为奴隶条件直接GAME OVER，基地建设仅体现在玩家探索地下城获得资源出售一定量后获得居民证，这之后就可以解锁城镇服务，随后玩家就能滚雪球发展经济，积累装备，打败L19。

这段确定本次整理的方向：复杂制度归剧情；资源出售与居民证构成简单城市成长；主角不购买奴隶，成为奴隶则结束本局。它没有给出资源表、贡献算法、门槛、服务效果或具体奴役条件。

### 提交请求

> 继续，将你的 L10 设计提一个 PR 到 books 仓。

作者之前同意继续细化服务、贡献与失败条件，本次进一步授权将设计提交 PR。这不是对助手每个例子和数值的逐项批准，也不是开发、改图、冻结或自合授权。原话来自本次作者对话，不把助手总结冒充另一份作者文件。

## 2. 批准状态

| 项目 | 状态与依据 |
|---|---|
| L10 制度复杂度只影响剧情、机制最简单 | 作者指定方向，见上方原文 |
| 探索售货、居民证、服务、装备成长、挑战 L19 | 作者指定方向；具体交易和服务细节是本稿建议 |
| 主角不购买／经营奴隶，成为奴隶即结束本局 | 不购买与成为奴隶即结束来自作者；不建设奴隶经营玩法是按此方向收束的设计 |
| 五建筑英文工作名、证前／证后表 | 沿用前轮助手候选并按最简玩法重整；未逐项批准。此次正文自足，不依赖旧草稿或图片 |
| 城市只新增累计售货进度和持证资格；一次领证开放服务 | 助手建议；不是存档字段或 API 定义 |
| 贡献按实际资源成交金币额累计，领证不再收费 | 助手建议；作者只要求“出售一定量”，没有裁定按价值还是数量 |
| 不出售同类计贡献原料；装备与药品转卖不计 | 轻量防刷建议，不是已核交易实现 |
| 通常 2–3 次短远征、`T=2R` | 未经试玩的节奏候选，非已定金币数或通关次数 |
| “接受以自由抵偿”、二次确认及独立失去自由终局 | 助手事件与表达建议；确切条件、入口、预警、替代路径和状态未定 |
| 零金、未领证、普通消费或成功战逃不自动触发奴役 | 本稿建议的可预防失败边界；不声称源码已有对应守卫 |
| 领证不等于留居，正常留居不是失败 | 依核心 C5 组织；后日谈和具体去留入口仍按该核心的批准状态处理 |

此前信用、产权、拍卖、债役账户和共同项目的讨论是可删改的头脑风暴。本次没有把它们改成必需系统，也不因未迁入就声称已删除游戏中的既有建筑／农田。后续要改变已有内容，须另核授权与事项。

## 3. 核心及现行回城口径

核心最初由[PR #239](https://github.com/sagitrs/sgstory-books/pull/239)整理入库。本次整理基线为 `87ba22249e304e14fb2622e320bc0fc8c37fe292`，不是原提案快照，也不是游戏运行验收。

- [核心 C3／C5](../../core/02-life-body-and-choice.md)：真死不可回收；成功战斗逃跑与真死分开，逃跑损失比例及执行细节按核心状态处理；归属、暂留与正式留居不能混同。新奴役终局不借此变成第二种复活或普通留居失败。
- [核心 C6／C7](../../core/03-cities-and-adventure.md)：四城的压迫／改善对照、探索供给与返城循环。该篇 C7 原正文说普通快速回城省略清路操作、不应先购买卷轴；篇首新增注记却称现行回城使用付费卷轴。这是可指认的不同口径，不把“已合入”视为它们已经一致。
- [#172 的早期回城裁定](https://github.com/sagitrs/sgstory-books/issues/172#issuecomment-5965202271)：第 1 项同时写传送与步行，道具需购买。它是历史依据，不独自覆盖之后的直接回复与版本裁定。
- [#259 的六裁](https://github.com/sagitrs/sgstory-books/issues/259)：战斗不可跳过、塔单向及串行事件等现行版本要求。[领队边界记录](https://github.com/sagitrs/sgstory-books/issues/259#issuecomment-5978054110)第三节区分步行回边与卷轴；[操作者五项批复](https://github.com/sagitrs/sgstory-books/issues/259#issuecomment-5979133432)第 1 项已确认卷轴为合法付费回城例外，不再把这项版本裁定写成未获批准。

**本稿的处理：**保留作者要求的 L10 探索／售货／服务循环，单列返程方式与证前预算的衔接，不修改核心正文或 #259 的实现。采用卷轴时也须保证未持证者能取得返程用品，并在资源、价格与恢复表中核其成本；不能用居民证锁住取得居民证必需的返程办法。是否继续沿用付费例外、还是明确修改普通返程口径，须在实施前由作者确认并同步相关文档，不由本 PR 默默选择。

本次没有验证地图通行、卷轴消费、治疗、售货、证件或终局在游戏中的可达性；来源评论、静态文档和已有代码事项不是这些功能的运行证据。

## 4. 未决项与范围

实施前需要确认：

1. 有效资源目录、普通远征产量与收购价；进度最终按数量还是价值。
2. 居民证门槛，以及证前休整、常见伤势处置、合法返程方式与成本。
3. 证后装备、补给、治疗、修理、食宿和寄存的小目录及效果。
4. 奴役条件的确切剧情节点、危险预告、可避免路径、确认和独立终局状态。
5. 远征区的新资源来源／刷新边界，确保不重复发放旧事件奖励。
6. 胜 L19 后去留的具体入口；L20 的新增协作／任务机制另行设计。

本次范围只有四份设计 Markdown：上级阅读索引、表现层入口、L10 正文和本来源记录。没有迁入四城图片、人物履历、规则全文或资产目录，没有修改游戏、引擎、价格配置、测试、pin、存档格式或 workflow。文档检查仅核文字、来源、范围和链接；没有玩法试玩、平衡试验、经济模拟或功能验收。未来开发与验证另行授权。
