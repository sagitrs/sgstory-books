## 1. 三种范围分别执行

| 范围 | 生效设计 | 不从另一范围自动迁入 |

旧恢复2HP的`ration`不是未来扎营物资；铜冠100旧硬币不是30新金币。币制换算未裁，不能只改名字当等值。普通远征成长方向也不自动撤销七名河首版脆弱规则。

- 乙真实穿戴`mail`（+3AC）和`heavy-wooden-shield`（+2AC），真实装备并使用`sword-quenched`。基础AC12、STR12、DEX12，不追加测试BAB、属性或祝福。

- 甲使用基础`sword`，无甲盾，只是低装备对照，不承担乙主基准承诺。甲乙同时改变武器与防御，不是甲盾单变量实验。

## 3. 普通远征只归档方向，首版追加功能为零

本版本不因核心04追加：扎营与三级疲劳、30金币物资、无硬限负重/丢弃UI、新通量、全物兑换、随机稀有库存、三段九层与主要Boss、完美隐藏选项、Boss再遇优势或反抗军。归档不等于取消这些后续方向，也不阻塞七名河按已裁规格交付。

普通远征实施前优先闭合四个设计问题：

1. **疲劳−5可推导。** 明确7层入口状态、结算机会、升档/封顶、9层战前营地与属性派生；7～8禁营本身不能推出9层恰好−5。不添加后台惩罚凑数。
2. **主要Boss和关底同战还是两战。** 作者有“每层关底”和“后三主要Boss”两种表述，尚未冻关系；不承诺9个主要Boss，不自动删除前六关底。
3. **战力上限真实成立。** k>0且X无限时`Q=b+kX`无界；需明确设施/装备上限或另裁通量顶，`Qmax`未批。
4. **结算范围与基础生存闭环。** 全物兑换未逐项冻结，城购装备、剧情/知识/凭证不能先清空。币制、30金币一两次净收益、旧免费赞助、稀有库存刷新/强度、资源标准份与搬运成本需对账。

反抗军解锁范围/赠品频率、防重、完美事件识别与跨阶段知识、Boss第二次遇见/优势次数、跨新游戏继承、伤症等继续见核心04的待定项，不在本次同意中顺手冻结。

## 4. 如何理解旧文档与验收

教程内容目录及审阅图片保留历史用途；旧“撤全部卷轴”“容量不足暂停”“无真头槽/零价”“预制节点快照”等不再与公开后裁同时充当现行规格。无真实容量门时记不适用，不制造假满包；真实交付/换装失败仍须零半提交。

返程结算按原因区分：本层机会和E9执行七名河脆弱，只有E9成功返城完成教程；旧付费卷轴不完成、不结脆弱。不得在全局`moveTo`上对所有返城一刀切。教程已处理记录防重与普通远征未来重复成长分账，不因世界题材复用而重奖或重新强制教学。

本PR只改文档。没有运行游戏、浏览器、真实存读、自然随机平衡、负控恢复或产品CI验收；固定两仓SHA/pin、同源构建、正式评审和实际CI仍须由相应交付记录证明。产品失败、环境作废、未覆盖分账，存档域登记不代Save.slots，旧全文重绘红账不由图册绿或排除通知面抵销。
