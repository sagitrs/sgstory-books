## 字体与主题

只声明系统字体栈：Noto Sans CJK SC → PingFang SC → Microsoft YaHei → system-ui → sans-serif。**不下载、不内嵌字体**；字体名是回退顺序，不证明目标平台实际命中或全 glyph 可用。中文正文桌面 18px、窄屏 17px 的默认 16px 根字号换算；用户字号／200% 缩放保留，状态与辅助字仍有独立层级。

冷灰实底／暖金操作、青色焦点框；禁用动作仍显示既有拒绝文字。该 CSS 不计算 HP 状态、AC、疗效、道具能力、回合消耗或存档门禁，保留既有 `choice`／背包点击路径。

窄屏保留上游 fixed HUD，为侧栏切换按钮与人物留位，并限制 HUD 高度、保留内部滚动。601–860px 的 CSS 视口中，非战期显式展开的 SugarCube 侧栏与正文分列；战期沿上游隐藏侧栏，取消该空白占位并为 fixed HUD 的画像高度让位、限高内滚。开栏范围对应本轮桌面 200% 缩放所见的 720px 视口，不是任意缩放／手机的全称保证。
