# 巴别场景清单（单源）

`#1814` 的**单源**：一份 JSON 同时喂两层（✗ 两份手抄）：

- **逻辑层**：`loadFixture(入口态) → dispatch(动作) → assertSave(期望态)`
- **渲染层**：`loadFixture(入口态) → Engine.play(段落) → DOM 结构断言`

**表＝渲染**（评审读 JSON 即读场景圣经；票面/comment 里的表只是它的一种排法）。

## 字段

| 字段 | 说明 |
|---|---|
| `id` | 短 slug（✗ 数字序号 —— 序会重排，引用会烂） |
| `段` | `span1`（1–10）｜`span2`（11–20）｜`cross`（跨段/跨域） |
| `入口态` | `{ fixture, 形 }`：`形` ∈ `裸状态形`（状态，✗ 存档）｜`具名`（已登记的命名夹具） |
| `动作` | **玩家真实入口**的序列（段落链接／按钮语义），✗ 直调底层 API |
| `断言.逻辑` | `assertSave` 期望（含**反向**一面） |
| `断言.渲染` | 结构选择器断言（`.noticebar`／`.inventory-links`／`data-item`／`data-panel`／创伤文案…），✗ 字节 golden |
| `锚` | 相关裁定锚（票/评论号）集合（≥1） |
| `主锚` | ★**恰一个**且 ∈ `锚` —— 一条场景＝**一个**裁定（其余锚只是旁证）|
| `同锚分案` | 可选：`{同锚, 面}` —— 两条**同主锚**时**必须**声明，且 `面` 须**互不相同**（「前提同源、断言面不同」⇒ 允许并存；✗「同一面拆两条」）|
| `层` | `logic`｜`render`｜`both` |
| `守的面` | 一句话：这条守的是**哪个回归** |
| `构造` | 可选：非平凡构造（保存→读档往返／顺序／跨场） |
| `备注` | 可选：待核事项（落地时钉实指） |

## 四条强制形（评审即按此判，与 `#1825` 四条同族）

1. **走真实动作** —— 动作须玩家入口可达；✗ 直调底层 API（否则「换成常量照样绿」）。
2. **双向断言** —— 正反两向都写（变 ＋ 不变／不可达）；✗ 裸 `includes` 单向。
3. **活行判据** —— 文本断言读**渲染出的 DOM 活行**；✗ 读源码文件内容。
4. **fixture 是状态不是存档** —— 裸状态形；信封形会被笔 1 契约拒（入口态 ≠ 存档）。

## 三个件（都在本目录）

| 件 | 用途 |
|---|---|
| `scenarios.json` | **单源**（改清单＝只改这一份） |
| `validate.mjs` | 自检：`node stories/babel/scenarios/validate.mjs` ⇒ 字段齐／id 唯一／锚非空／`层=both ⇒ 两层断言齐`／动作非空／fixture 形合法；失败＝**干净红 ＋ 汇总**（崩溃走具名支） |
| `render-table.mjs` | 票面/评审的**表渲染**：`node …/render-table.mjs > table.md`（✗ 手抄 —— 表与 JSON 永不漂移） |

★**接线**：`tests/scenario/run.mjs`（tester-3/4 的场景链）落地时，**开头先跑 `validate.mjs`**（清单不合形 ⇒ 场景链不该开跑）。

## 去重口径（**可执行** —— 见 `validate.mjs`）

**按 `主锚` 去重**：同一裁定原则上**只出一条**；要两条 ⇒ 两条都要写 `同锚分案.面` 且**互不相同**。
★这条口径**不是散文**：`validate.mjs` 会查「主锚恰一个且 ∈ 锚」「同锚必分案」「分案面不得逐字相同」「分案.同锚 必须指向自己的主锚」。
现存两组分案（示例）：`books#70`＝**段内**三点链／**段间**全图封闭；`#1835`＝一段**canonical 声称进门**／二段**非 canonical 静默漏**。
已落别处、本清单不重复：`#1825` 四条（创伤往返／死亡回溯清档／异槽共存／护栏计数不随档）。
