## 字段

| 字段 | 说明 |
|---|---|
| `id` | 短 slug（✗ 数字序号 —— 序会重排，引用会烂） |
| `段` | `span1`（1–10）｜`span2`（11–20）｜`cross`（跨段/跨域） |

| `入口态` | `{ fixture, 形 }`：`形` ∈ `裸状态形`（状态，✗ 存档）｜`具名`（已登记的命名夹具） |
| `动作` | **地点/面板级**真入口的序列 —— 该地点的 `availableActions` 或**出边文案**（`走向料场` 这类地图边**也算**）／面板按钮；✗ 直调底层 API；✗ 放**流程步**（那是 `步骤`） |

| `断言.渲染` | 结构选择器断言（`.noticebar`／`.inventory-links`／`data-item`／`data-panel`／创伤文案…），✗ 字节 golden |
| `锚` | 相关裁定锚（票/评论号）集合（≥1） |

| `同锚分案` | 可选：`{同锚, 面}` —— 两条**同主锚**时**必须**声明，且 `面` 须**互不相同**（「前提同源、断言面不同」⇒ 允许并存；✗「同一面拆两条」）|
| `层` | `logic`｜`render`｜`both` |
| `守的面` | 一句话：这条守的是**哪个回归** |
| `构造` | 可选：非平凡构造（保存→读档往返／顺序／跨场） |
| `备注` | 可选：待核事项（落地时钉实指） |

## 四条强制形（评审即按此判，与 `#1825` 四条同族）

1. **走真实动作** —— 动作须玩家入口可达；✗ 直调底层 API（否则「换成常量照样绿」）。
2. **双向断言** —— 正反两向都写（变 ＋ 不变／不可达）；✗ 裸 `includes` 单向。
3. **活行判据** —— 文本断言读**渲染出的 DOM 活行**；✗ 读源码文件内容。
4. **fixture 是状态不是存档** —— 裸状态形；信封形会被笔 1 契约拒（入口态 ≠ 存档）。
   ★**可判即判**：`validate.mjs` 对 inline `入口态.数据` 查存档信封键（`state`／`saveVersion`／`version`）⇒ 出现即红。
5. ★**渲染断言只断 UI 真会显示的，且每个值/子串须带实指**（署 **`writer` ＋ `writer-2`**）：
   **`断言.渲染` 里每个被断言的值/子串，须带 `文件:行`（如 `play.twee:58`）或**选择器**（如 `.noticebar`／`[data-panel="hp"]`）—— ★**指不出 ⇒ 该断言未成立**。
   **机械可核**：`validate.mjs` 对每条 `断言.渲染` 查「有 `文件:行` 或选择器」⇒ 两者都无即红（＋刀 K13）。
   理据（本轮实证）：**5 处错全是同一形** —— 断言了「逻辑层算得出、而 UI **不产出**」的东西（遭遇面板**只渲染敌名**（✗无 HP/AC/CR）；道具行**仅 `>1`** 才加 `×N`（✗ 无「耗尽」标注）；本故事**无**「资源面板」）
   ⇒ **带实指是唯一能当场拦住的形**（与 `#1769` 检查①同判据、两层应用）。
